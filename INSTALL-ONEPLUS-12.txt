RBI MENTAL MATHS — ONEPLUS 12 INSTALL GUIDE

This ZIP is the Android app source project. It is not an APK yet. Build the APK using one of the two routes below.

RECOMMENDED: BUILD THE APK WITH GITHUB ACTIONS
You do not need Android Studio for this route.

1. On a computer, download and extract rbi-mental-maths-android-project.zip.
2. Sign in to GitHub and create a new repository (a private repository is fine).
3. In the new repository, choose Add file > Upload files.
4. Upload the CONTENTS of the extracted project folder, not a nested folder.
   Make sure the hidden file path `.github/workflows/build-apk.yml` is included.
5. Commit the files to the `main` branch. The APK workflow starts automatically.
6. Open the repository's Actions tab.
7. Open the run named "Build RBI Mental Maths APK".
8. When it finishes successfully, download the artifact named
   `rbi-mental-maths-debug-apk`.
9. Extract that artifact ZIP. You will find `app-debug.apk` inside it.
10. Send `app-debug.apk` to your OnePlus 12 (USB, Drive, or another file transfer).
11. Open the APK on your phone. When Android asks, allow the file manager/browser
    you're using to install unknown apps. Return to the installer and tap Install.
12. Open RBI Mental Maths and start practising. Grant notification permission.
13. To enable reminders, go to Settings inside the app and switch on
    "Three-hour practice reminders".

ALTERNATIVE: BUILD USING ANDROID STUDIO
1. Install Android Studio on a computer.
2. Extract the project ZIP.
3. In Android Studio, choose Open and select the `rbi-mental-maths-android` folder.
4. Allow Gradle project sync. Install Android SDK Platform 35 and Build Tools 35
   if Android Studio prompts you.
5. Use JDK 17 or newer. The included Gradle build uses Android Gradle Plugin
   8.13.2 with Gradle 8.13.
6. Open the Build menu and choose Build Bundle(s) / APK(s) > Build APK(s).
7. The APK output is:
   `app/build/outputs/apk/debug/app-debug.apk`
8. Transfer it to the OnePlus 12 and follow steps 11–13 above.

HOW THE APP REMEMBERS YOUR PRACTICE
- Topic/skill accuracy, average response time, recent errors, skips, review priority,
  difficulty offsets, round history and exact question history are stored locally
  in the app's private data.
- The app does not require sign-in and has no server/database account.
- Use Settings > Export JSON before uninstalling or changing phones.
- Use Settings > Import JSON on the new installation to restore your profile.
- Uninstalling the app generally removes its local data unless you restore a backup.

REMINDER LIMITATION
The three-hour reminder begins three hours after you enable it. It reschedules after
each reminder and after a device reboot. These are inexact Android alarms: battery
optimisation/Doze can delay them, and notification permission must be granted.

IMPORTANT
The generated APK is a debug-signed personal-install build. It is suitable for
sideloading on your phone but is not a Play Store release or a production-signed APK.
